# Machine Learning & Data Science Labs · Alexis Torres

Ruta práctica, progresiva y ejecutable en Google Colab. Los notebooks avanzan desde fundamentos estadísticos y ML clásico hasta Big Data, causalidad, monitoring y MLOps.

Cada lab intenta mantener la misma estructura: **objetivos → intuición → fundamento → ejemplos → comparación → métricas/visualización → usos → errores comunes → ejercicios → extensiones**.

## Cobertura

**Fundamentos:** estadística, probabilidad, EDA, leakage, bias/variance, validación y generalización.  
**Supervisado:** regresión, clasificación, regularización, árboles, ensembles, SVM, KNN, Naive Bayes, boosting.  
**No supervisado:** clustering, GMM, PCA, t-SNE, UMAP.  
**Especializados:** forecasting, anomaly detection, recommender systems, survival analysis, spatial ML, imbalance, online/semi-supervised/active learning.  
**Data Engineering:** Hadoop, HDFS, YARN, MapReduce, Spark, Spark SQL, MLlib, streaming.  
**Responsible/decision science:** explainability, calibración, thresholding, A/B testing, causal inference.  
**Producción:** pipelines, data quality, drift, MLflow, AutoML, serving y MLOps.

> Los labs son educativos y están diseñados para experimentar. En proyectos reales, el split, las métricas, los datos, la gobernanza y los criterios de despliegue deben adaptarse al dominio.
